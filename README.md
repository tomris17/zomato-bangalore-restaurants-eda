This repository contains an exploratory data analysis (EDA) project focusing on Bangalore's restaurant ecosystem using data from Zomato. The analysis investigates restaurant ratings, cost distributions, popular cuisines, location hotspots, and online order availability.

---

## 📊 Project Overview
* **Objective:** Uncover statistical insights and trends regarding dining preferences, pricing structures, and geographical hotspots across Bangalore's food scene.
* **Key Steps:**
  * Data cleaning, handling missing values, and parsing financial/rating fields (e.g., converting cost strings and ratings to numeric formats).
  * Exploratory Data Analysis (EDA) examining the relationship between cost, ratings, table booking, and online ordering.
  * Geographical distribution and cuisine popularity analysis.
  * Interactive web dashboard deployment via **Streamlit** to filter and explore restaurant metrics dynamically.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy** (Data Cleaning & Aggregation)
* **Matplotlib & Seaborn** (Statistical Charts & Visualizations)
* **Streamlit** (Interactive Dashboard)
